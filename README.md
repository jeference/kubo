# Kubo

Plataforma que conecta quem quer comprar objetos impressos em 3D a parceiros que os imprimem. O cliente cria o modelo a partir de um texto ou de uma imagem, visualiza e compra da Kubo.

## Estrutura do monorepo

| Pasta | O que é |
|---|---|
| [`prototipo/`](prototipo/) | Protótipo de uma página (Django + Next.js) para validar a UX de criação do modelo 3D: texto/foto → imagens → modelo 3D (Trellis 2 via Runware). |
